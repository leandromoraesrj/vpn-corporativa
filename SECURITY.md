# Segurança

## Relato de vulnerabilidades

Não publique credenciais, configurações locais, endereços de infraestrutura ou
detalhes exploráveis em issues públicas. Use o recurso **Report a vulnerability**
do GitHub, quando habilitado no repositório, para enviar um relato privado com
impacto, versão afetada e passos mínimos para reprodução.

Não inclua senhas, tokens, certificados privados nem o conteúdo de
`~/.config/vpn/connection.conf` no relato.

## Escopo

A versão mantida atualmente é a `1.0.1`. Correções de segurança serão documentadas
nas notas da versão correspondente.
